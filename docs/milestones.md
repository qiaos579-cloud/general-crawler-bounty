# 时间节点建议

## 第一阶段：基础框架（第 1—2 周）

完成项目框架、任务模型、普通网页采集、公开接口采集、清洗去重、日志和结果导出，形成最小可运行版本。

## 第二阶段：能力扩展（第 3—4 周）

增加批量任务、定时调度、数据库存储、失败重试、采集器模板和基础运行状态查询；选择 2—3 个实际业务数据源完成适配验证。

## 第三阶段：动态采集与管理（第 5—6 周）

接入 Playwright 动态页面采集，完善任务管理、运行监控、异常记录和配置管理；根据需要增加简单管理页面。

## 第四阶段：业务接入与验收（第 7—8 周）

按业务需求增加典型网站、公开 API 或智能体生态适配器，开展稳定性测试、数据质量检查、文档整理和验收演示。

> 实际时间可根据目标站点数量和复杂程度调整。核心策略是先完成平台，再逐步扩展数据源。
